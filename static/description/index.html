Widget Add Sum to Top Tree View

This module provides a custom widget that adds a sum to the top of tree views in Odoo.

Features

  • Custom tree view widget with sum functionality.
  • Supports inline editing for specific rows.
  • Customizable formatting for monetary and float values.

Usage

To use this module, include the widget in your tree views by specifying the `sum_top_tree` widget in the XML view definition.

Dependencies

This module depends on the `base` module.
